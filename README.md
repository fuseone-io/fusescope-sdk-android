# FuseScope Android SDK

Real User Monitoring for Android apps, sending to [FuseScope](https://github.com/fuseone-io/fusescope):
a thin distribution over [OpenTelemetry Android](https://github.com/open-telemetry/opentelemetry-android).

Status: scaffold.
